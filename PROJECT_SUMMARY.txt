📋 API ENDPOINTS (15 TOTAL)
═══════════════════════════════════════════════════════════════════════════════

AUTHENTICATION
  POST   /api/auth/register      - Create account
  POST   /api/auth/login         - User login

MENU
  GET    /api/menu               - Get all items
  POST   /api/menu               - Add item (Admin)
  PATCH  /api/menu/:id           - Update item (Admin)

ORDERS
  POST   /api/orders             - Create order
  GET    /api/orders             - Get my orders
  GET    /api/orders/kitchen     - Get kitchen orders
  PATCH  /api/orders/:id/status  - Update status (Kitchen)

INVENTORY
  GET    /api/inventory          - Get inventory (Admin)
  POST   /api/inventory          - Add item (Admin)
  PATCH  /api/inventory/:id      - Update item (Admin)

TABLES & ANALYTICS
  GET    /api/tables             - Get tables (Admin)
  POST   /api/tables             - Create table (Admin)
  GET    /api/analytics/dashboard - Get stats (Admin)
